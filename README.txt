SIMORA BOT — стартовый проект

ВАЖНО
- Никогда не публикуйте BOT_TOKEN и не отправляйте его в чат.
- Для первой тестовой версии не просите пользователей присылать QR активации eSIM.
  QR может содержать секретный код, позволяющий установить профиль. Используйте
  фото подтверждения без секретных кодов и персональных данных.
- Перед фактической перепродажей проверьте правила оператора и право передачи eSIM.

Что умеет эта заготовка
- /start — меню пользователя
- Выбор оператора и отправка фото
- Уведомление администратору с кнопками принять/отклонить
- Профиль и список последних заявок
- /myid — узнать Telegram ID
- /admin — панель администратора
- /price МТС 500 — изменить цену (пока текстовое значение)

Запуск
1. Установите Python 3.11+ на хостинге.
2. Установите зависимости: pip install -r requirements.txt
3. Добавьте переменные окружения:
   BOT_TOKEN = токен от BotFather
   ADMIN_ID = ваш числовой Telegram ID
4. Запустите: python bot.py

Сначала узнайте ADMIN_ID:
- временно запустите бота с тестовым ADMIN_ID=0
- откройте бота и отправьте /myid
- остановите бота, задайте полученный ADMIN_ID и перезапустите.

Для iPhone можно редактировать проект через браузерный IDE/репозиторий и
развернуть его на облачном хостинге. Не храните токен прямо в bot.py.
